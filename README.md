# FirefoxCustomCSS

This repo contains my custom `userChrome.css`, made purely for my own convenience. It includes:

- A sliding address bar that hides when not in use.
- A sliding bookmarks toolbar that hides when not in use.

This CSS is pretty important to me (at least). It helps maximize the available page content without messing with display scaling or changing font sizes.

Built entirely from scratch. Took me decades to make. Just kidding, it took 2 days, but still, **2 whole days for some CSS!**

And before you ask, don't copy this. Consider that a friendly but straightforward warning. This is made specifically for my setup and personal use. Nothing more, nothing less.
